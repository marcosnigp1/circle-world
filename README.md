# Description

This is a game about tolerance, coexistence, and greater consciousness about the diversity that exists in our world. For this, geometrical figures are used as an analogy. The player will be able to use different geometrical characters in order to progress through the levels, but challenge awaits in unexpected ways.

As for the controls, you have to use the keyboard to move and interact (the game will indicate which keys), and the mouse to interact with the menu's buttons.

# Frameworks

I mainly used [p5.js](https://p5js.org/) and [Matter.js](https://www.brm.io/matter-js/) to develop this game. The builds available on the game's [itch.io page](https://marcosni-gp1.itch.io/circled-world) were created using [Electron](https://www.electronjs.org/).
